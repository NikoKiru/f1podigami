# Rebrand Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the bar-chart logo and assorted pills with the approved plate mark, stacked wordmark and plate badge family, add the scorigami-style last-race verdict, and cut the landing page on phones from ~4½ screens to ~2 with "Most likely trios" above the fold.

**Architecture:**
- The mark lives once, as an SVG string builder in a new `src/build/brand.py`. The header, drawer, `favicon.svg` and a Playwright render script all consume it.
- Badges become shared `.plate*` utility classes with theme tokens in `assets/style.css`. Builders add those classes, and per-component badge colours and radii are deleted.
- Phone trimming is markup that exists once plus `@media (max-width: 600px)` rules in `assets/podigami.css`. A few phone-only fragments (short labels, the Explore list, toggles) are hidden on desktop. Desktop markup and content are otherwise untouched.

**Tech Stack:** Python 3.11+ string-built HTML, plain CSS, vanilla JS (`assets/podigami.js`), pytest, Playwright (`.venv` only, for e2e tests and the icon render script).

**Spec:** `docs/superpowers/specs/2026-11-06-rebrand-design.md`. Read it first. Approved mockups are in `.superpowers/brainstorm/1139-1793977655/content/`.

## Global Constraints

- Run every tool through `.venv/Scripts/python.exe -m …`.
- Work on branch `feature/rebrand` off `develop`.
- Mobile breakpoint is exactly `@media (max-width: 600px)`.
- `podigami.css` styles five pages (all but Combinations). Every landing-only phone rule is scoped under `.landing`, the class Task 7 puts on the landing page's `<main>`, so other pages keep their hook cards, "Keep exploring" grid and FAQ as they are.
- All CSS and JS URLs go through `_layout.asset()`. No bare asset URLs.
- Escape every data value interpolated into HTML with `esc()` / `html.escape()`.
- The mark's red is `#e10600` (= `--accent`). The plate SVG is exactly the spec's "Approved SVG", with only the mask id parameterised.
- Wordmark copy is "Formula 1" over "Podigami", rendered uppercase via CSS. Page `<title>`s and schema.org name stay "F1 Podigami".
- Plate corners are `4px`. Chips are `6px`. Plate type is uppercase, weight 800, letter-spacing `.14em`–`.16em`, about `9.5px`. NEW and PODIGAMI are weight 900 *italic*.
- Within badges, red (`--accent`) is only for NEW and PODIGAMI. Do not change any non-badge red: the nav line, card rails, page-`<h1>` "F1", links, focus, the hero %, the selected bar and ranked rails.
- Don't touch fonts, section headings, panel styling, table layouts or existing tokens beyond the new `--plate-*` / `--chip-bg` tokens. No skewed decorations.
- Mockup details the spec doesn't name are sketches. Keep today's styling for them: dimmed repeat rows, 6px bars, two-decimal %, card rails, full chip labels.
- Historic driver names never appear as three-letter codes or team-colour dots.
- Every PR carries a `RELEASE_NOTES.md` entry. `README.md` is updated wherever it shows or describes the logo or the landing page.
